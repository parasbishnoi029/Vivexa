# AI Data Analytics Platform

## AI Software Development Lifecycle (AI-SDLC)

Version: 1.0

Priority: Mandatory

Status: Required

---

# 1. Purpose

This document defines how Artificial Intelligence will be used during software development.

Google AI Studio is a development assistant.

It is NOT the architect.

It is NOT the reviewer.

It is NOT responsible for final code quality.

Every generated feature must be reviewed before being committed.

# 9. Code Review Checklist

Does the code compile?

Does it follow architecture?

Does it follow coding standards?

Does it introduce security risks?

Does it duplicate existing logic?

# 11. Refactoring Rules

Never rewrite working modules without a reason.

Prefer incremental improvements.

Avoid unnecessary changes.

---

# 12. Commit Policy

Never commit directly after AI generation.

Review first.

Run tests.

Then commit.

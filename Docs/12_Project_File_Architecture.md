# 1. Purpose

This document defines the complete folder structure of the project.

Every file generated by Google AI Studio must follow this structure.

No file should be placed outside this architecture without approval.

# 15. File Rules

No file larger than 500 lines.

No folder with mixed responsibilities.

One responsibility per module.

---

# 16. Naming Rules

snake_case

Folders

---

# 17. Import Rules

Never use circular imports.

Keep dependency direction clean.

Frontend never imports backend.

Analytics never depends on UI.

# AI Data Analytics Platform

## User Flow & Product Flow

Version: 1.0

---

# 1. Purpose

This document defines every user interaction inside the platform.

Before writing code, we must know:

- What the user sees
- What the user clicks
- What happens behind the scenes
- Which APIs are called
- Which database tables are updated
- Which AI modules are executed

No page or feature will be developed before its flow is documented.

---

# 2. User Types

The platform supports three user roles.

## Guest

Not logged in.

Can:

- Visit website
- View features
- View pricing
- View documentation
- Contact sales
- Login
- Register

Cannot:

- Upload data
- Use AI
- Access dashboard

---

## Registered User

Can:

- Login
- Upload datasets
- Connect databases
- Analyze data
- Generate reports
- View history
- Manage profile
- Request plan upgrade

Cannot:

- Access admin dashboard
- Change other users
- View system logs

---

## Admin

Can:

- View all users
- Upgrade plans
- Suspend users
- Reset accounts
- View usage
- View storage
- Access logs
- Manage announcements

# 19. Product Philosophy

The user should never need to know:

- SQL
- Machine Learning
- Python
- Statistics

The platform performs these tasks automatically.

The user only focuses on business questions.

---

# 20. User Experience Rules

Every page should:

Load quickly

Have clear navigation

Support dark mode

Support keyboard shortcuts

Show progress indicators

Provide helpful error messages

Never expose technical complexity

---

# 21. Success Criteria

A new user should be able to:

Register

Upload a dataset

Analyze data

Generate a report

Understand the results

within 10 minutes without reading documentation.

---

# 22. Decision Summary

Three user roles.

Simple onboarding.

Guided workflow.

AI-first experience.

No technical knowledge required.

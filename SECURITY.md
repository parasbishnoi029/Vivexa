# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.2.x   | :white_check_mark: |
| < 3.2   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Vivexa, please send an email to security@vivexa.ai. All security vulnerabilities will be promptly addressed.

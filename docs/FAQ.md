# Vivexa FAQ

**Q: Can I analyze large datasets?**
A: Currently, datasets are limited to what can be handled by standard cloud buckets (100MB). For massive datasets, consider sampling before upload.

**Q: Is my data secure?**
A: Yes, data is stored securely in Supabase with user-specific Row Level Security (RLS) preventing unauthorized access.

**Q: What AI model is used?**
A: We use Google's Gemini models for advanced data science reasoning and insights.
